Dashboard privacy policy

Last updated November 27, 2026

Dashboard is a personal app used only by its developer, with their own Google account. It is not offered to anyone else.

What Google data it uses

  • Google Tasks (read-only, tasks.readonly): task lists, task titles, notes, due dates and whether each task is done.
  • Google Calendar (read-only, calendar.readonly): the title, start and end time, and location of calendar events.

How it is used

This data is used only to display the developer's own tasks and events on their own Dashboard page. Dashboard cannot create, change or delete anything in Google.

Where it is kept

The data is stored only on the developer's own computer, in local files that the Dashboard page reads. The sign-in key is stored in the computer's operating-system credential store, not in a file. Nothing is uploaded to any server run by Dashboard; Dashboard has no server of its own on the internet.

Sharing

Google user data is never sold, shared with, or transferred to anyone. It is not used for advertising, and it is not used to train any AI or machine-learning model.

Dashboard's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/connections. Removing it stops all further reading; the local copies can then be deleted from the developer's computer.

Contact

Questions go to the support email shown on this app's Google sign-in screen.
